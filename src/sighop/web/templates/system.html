Collection logs in to each selected repeater with a blank guest password — no other password is ever sent — then asks for its status and its neighbour list. A repeater whose guest password is set does not answer, which is recorded as login unanswered, the same as one out of range. Only repeaters ticked on the contacts page are polled: {{ c.selected }} selected, of which {{ c.in_window }} were heard within the recency window now.
