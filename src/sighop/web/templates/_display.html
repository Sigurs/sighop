{# How the panel draws a status, a public key and a timestamp (`web-display`). Dense views show a glyph and the few figures that tell one row from another; what the status *means* moves to hover (`title`) and to a visually hidden span, so a screen reader reads the statement rather than a bare glyph, and nothing a spec requires to be stated leaves the page. The glyph, not the colour, is what tells one status from another. #} {# One `render.Status`. The visible part is hidden from assistive technology because the explanation already carries its numbers and its reason. #} {% macro status(s) -%} {%- if s.glyph %}{{ s.glyph }}{% endif -%} {%- if s.figures %}{{ s.figures|join(' · ') }}{% endif -%} {%- if s.reason %}{{ s.reason }}{% endif -%} {{ s.explanation }} {%- endmacro %} {% macro statuses(list) -%} {%- for s in list %}{{ status(s) }}{% if not loop.last %} {% endif %}{% endfor -%} {%- endmacro %} {# A public key: its first three bytes, the whole key on hover and behind the copy control. Where neither the clipboard nor an off-screen copy is available, `display.js` fills it with the full key and selects it for copying by hand; it is positioned out of the flow, so the abbreviation beside it never moves and no column changes width. #} {% macro key(value) -%} {%- set full = value if value is string else value.hex() -%} {{ full[:6] }}… {#- #} {#- #} {%- endmacro %} {# The copy control alone, for a received channel message's paths: one path per line, hops joined by `->`.
